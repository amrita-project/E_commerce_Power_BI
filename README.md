# Human Resources (HR) Workforce Analytics Dashboard

## 🎯 Project Objective
This interactive Power BI dashboard provides HR executives and leadership teams with data-driven insights into corporate workforce distribution, departmental headcounts, global geographic hubs, and annual payroll allocations. It transforms raw employee records into actionable operational talent metrics.

## 📊 Core Business Metrics Tracked
* **Total Annual Payroll:** Monitored via optimized callout metric cards to prevent departmental budget leakage.
* **Employee Headcount:** Evaluated across different operational domains (IT, Sales, HR, Engineering) to optimize workforce planning.
* **Geographic Talent Distribution:** Segmented by global manufacturing and corporate office hubs (including Brazil and local city centers).
* **Demographic Baseline Analysis:** Tracks employee age metrics to support long-term corporate succession planning.

## 🛠️ Technical Stack & Skills Demonstrated
* **Data Cleansing & ETL:** Engineered via Power Query to clean null values, structure date columns, and format raw currency values.
* **UI/UX Design Engineering:** Implemented a modern dashboard design utilizing unified dark and corporate pastel accent coloring, structured padding layout blocks, and clear metric visual hierarchies.
* **Advanced Filter Interactivity:** Configured synchronized dynamic slicers (Country/City filtering) to allow multi-tier drill-down operations for regional HR managers.
